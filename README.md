# 1st Texas Realtors

A Vite-powered responsive front-end recreation inspired by the supplied Base Habitation reference. The project is configured for deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

## Deploy to Vercel

Import the GitHub repository into Vercel. Vercel will detect Vite automatically; the repository also includes `vercel.json` with the build command and `dist` output directory.

Recommended settings:

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

> Image URLs are used as visual placeholders in this recreation. Replace them with licensed project assets before publishing.
